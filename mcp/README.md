# MCP-серверы проекта PhoneRank

Здесь хранятся конфигурации и документация для MCP-серверов, подключённых к проекту.

## Уже подключённые MCPs

| MCP | Что умеет | Использование в проекте |
|-----|-----------|------------------------|
| **Claude Preview** | Браузерный превью сайта, скриншоты, клики | Просматривать готовый сайт прямо в Claude |
| **Computer Use** | Управление рабочим столом, скриншоты | Тестировать UI, находить баги |
| **Context7** | Актуальная документация Next.js, Tailwind, React | Писать код по свежей документации |
| **Canva** | Создание дизайнов, баннеров | Создать баннер для главной страницы |
| **Google Drive** | Хранение и чтение файлов | Сохранить экспорт данных телефонов |

## Рекомендуемые MCPs для добавления

### 1. Supabase MCP
Для перехода от статических JSON-данных к реальной базе данных.
```
Установка: npx -y @supabase/mcp-server-supabase@latest
Польза: хранить 1000+ телефонов, фильтровать на сервере, добавлять пользовательские оценки
```

### 2. Vercel MCP
Для деплоя сайта в один клик.
```
Установка: npx -y @vercel/mcp-adapter
Польза: опубликовать PhoneRank в интернет, CI/CD, аналитика
```

### 3. Next.js Devtools MCP (Vercel)
Для отладки во время разработки.
```
GitHub: https://github.com/vercel/next-devtools-mcp
Польза: видеть ошибки, логи, состояние компонентов прямо в Claude
```

### 4. Brave Search MCP
Для автоматического обновления цен и характеристик телефонов.
```
Польза: искать актуальные цены, новые модели, обзоры
```

## Как подключить новый MCP

Открой `Настройки Claude Code → MCP Servers` и добавь конфиг:
```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": ["-y", "@supabase/mcp-server-supabase@latest", "--supabase-url", "...", "--supabase-anon-key", "..."]
    }
  }
}
```
