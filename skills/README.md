# Скиллы проекта PhoneRank

Здесь хранятся скиллы Claude Code, полезные для разработки и сопровождения этого проекта.

## Встроенные скиллы (уже доступны)

| Скилл | Команда | Когда использовать |
|-------|---------|-------------------|
| **pptx** | `/pptx` | Создать презентацию с рейтингом телефонов |
| **pdf** | `/pdf` | Экспортировать рейтинг в PDF-документ |
| **xlsx** | `/xlsx` | Экспортировать данные телефонов в Excel |
| **security-review** | `/security-review` | Проверить код на уязвимости |
| **review** | `/review` | Ревью кода перед деплоем |
| **simplify** | `/simplify` | Упростить и улучшить код |
| **init** | `/init` | Обновить CLAUDE.md документацию |

## Скиллы для установки из npm

### phone-specs-api
Источник актуальных характеристик телефонов.
```bash
# Репозиторий: https://github.com/azharimm/phone-specs-api
# Использование: npm install phone-specs-api
# Польза: автоматически обновлять specs из реального API
```

### gsmarena-scraper
Скрейпер данных с GSMArena.
```bash
# Репозиторий: https://github.com/karnadii/gsmarena-scraper-json
# Польза: получать данные для новых телефонов автоматически
```
